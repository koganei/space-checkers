# Artwork provenance

`reference.png` is the user's selected Space Play concept generated in this chat.

`app/src/main/assets/piece-star.png` and `piece-ring.png` were created with the built-in image-generation tool, using transparent backgrounds. They are neutral master sprites recolored by the Android renderer, so every color keeps the same shading. Both full prompts are below. There are no remote runtime assets.

## Star prompt

Create a single production game sprite for an Android children's checkers app. A circular molded toy checker with a raised five pointed star centered in its circular recessed face. Beautiful soft three-dimensional molded matte-plastic rendering, softly beveled rounded rim, smooth continuous lighting, not flat vector. Almost directly overhead camera, very slightly showing bottom thickness like a checker lying on a board viewed from above. Entire checker neutral silver-gray / off-white, monochrome to be recolored in software. Center face approximately RGB 180, highlights near 245, shadows near 65. Raised star has rounded corners and subtle depth with upper left highlights and lower right shadows. Disc occupies 88% of square canvas, perfectly centered. Single piece only, no text, no other objects. Transparent background with only a very subtle contact shadow immediately below checker. Crisp high quality game asset.

## Font

Fredoka variable font from the [Google Fonts repository](https://github.com/google/fonts/tree/main/ofl/fredoka), bundled under the SIL Open Font License. License text: `app/src/main/assets/FONT-LICENSE.txt`. Weight 400 for supporting text, 600 for headings. Decoration and icons are project-owned native drawing code.

## Alien portraits

Pip, Bloop, Ziggy and Luma are native vector-style Canvas illustrations in `AlienArt.java`, using rounded silhouettes, radial body shading, shared eye highlights, cheek blush and distinct antenna/fins. They use no downloaded or generated raster artwork and remain sharp when resized.

## Original sound effects

The four `app/src/main/res/raw/sfx_*.wav` files are original synthesized space chimes, generated by `scripts/generate-sounds.py` with Python's standard library. No external samples or licenses are required. Mono 22,050 Hz PCM, 16-bit, with soft attack/release envelopes and conservative amplitude. The app plays them locally through Android SoundPool.
